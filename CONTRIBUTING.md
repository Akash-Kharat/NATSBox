# Contributing

Thanks for helping improve NATSBox.

1. Fork and create a branch from `main`.
2. Set up: see [docs/development.md](docs/development.md).
3. Make your change with tests where practical.
4. Run `npm run typecheck && npm test && npm run build`.
5. Update docs and [CHANGELOG.md](CHANGELOG.md) for user-visible changes.
6. Open a pull request using the template; CI must pass.

Please use clear commit messages (e.g. `fix: handle empty subject`). Report security issues privately per [SECURITY.md](SECURITY.md), not in public issues.
